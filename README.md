# 截录 JieLu — macOS 截屏、长截图与录屏工具

一个原生 macOS 截屏与录屏应用。支持窗口/框选区域的普通截屏与自动滚动长截图，也支持窗口、全屏或框选区域录屏。

## 下载

预构建安装包（Apple Silicon / macOS 14+）：

**https://github.com/sevenult1219/macos-screenshot-recorder/releases/latest**

> 安装包使用 Apple Development 证书签名，未经过 Apple 公证。首次打开若被 Gatekeeper 拦截，请在 Finder 中右键应用 →“打开”，或到“系统设置 → 隐私与安全性”中允许。

- 安装位置：`/Applications/截录.app`
- 系统要求：macOS 14 或更高（已在 macOS 26 上测试）
- 技术栈：SwiftUI、ScreenCaptureKit、Accessibility、CoreGraphics

> 为保留已有文件，输出目录继续沿用 `图片/长截屏` 和 `影片/长截屏`。新应用名为“截录”。


## 界面

打开应用先进入**首页**，只展示两个任务入口：**截屏** 和 **录屏**。选择一个任务后进入独立任务页，左上角可返回首页。

截屏页和录屏页使用同一套结构：

1. **选择范围**：截屏为窗口/框选区域；录屏为窗口/整个屏幕/框选区域。
2. **选择目标**：窗口选择打开同一个窗口选择面板；区域选择打开同一个框选浮层；整个屏幕直接使用当前屏幕。
3. **设置选项**：截屏设置普通/长截屏；录屏设置帧率和音频开关。
4. 底部主按钮开始。

普通截屏只取当前一帧；长截屏会激活窗口自动滚动并拼接。两种方式共用同一套原始像素与无损 PNG 流程。

截屏和录屏各自维护窗口与区域选择，互不影响。权限状态只在首页右上角按需展开。

## 功能

- **统一的截屏/录屏页**：两者都使用“① 选择范围 → ② 选择目标 → ③ 设置选项 → 底部开始”的同一套结构。
- **截屏任务**：同一页内切换“窗口 / 框选区域”和“普通截屏 / 长截屏”。
- **普通截屏**：截取窗口或框选区域当前的一帧，按原始像素保存为无损 PNG，不自动滚动。
- **窗口选择**：读取所有可见窗口，显示实时缩略图，支持搜索和刷新。
- **框选截屏**：点击“框选区域”（或按 ⌘⇧2），在屏幕上拖动框出任意区域；普通模式保存当前画面，长截屏模式会找到区域下方的窗口并自动滚动拼接。
- **自动滚动，不限长度**：激活并抬起所选窗口，持续滚动到页面底部或手动停止；没有屏数或像素高度上限。
- **磁盘缓冲**：每屏只把新出现的像素行写入磁盘，内存占用不随长图长度增长；仅受磁盘剩余空间约束。
- **像素级拼接**：在低分辨率下先做粗匹配，再用全分辨率搜索精修，自动忽略固定页头和右侧滚动条干扰；拼接过程不缩放、不重采样。
- **实时状态**：主窗口自动隐藏，屏幕顶部显示可拖动的悬浮控制条，可随时停止。
- **无损画质**：按窗口 `pointPixelScale` 取原始像素，流式写入无损 PNG；不会为了长度压缩、缩放或使用有损格式。
- **原尺寸预览**：自绘分块预览只渲染可见区域，可切换“适合宽度 / 100% / 200%”，超长图片也能流畅查看并检查文字锐度。
- **上传分段导出**：把超长图按约 2000 px 高度拆成多张原始宽度 PNG，适合上传 ChatGPT 等会压缩超长图的平台。
- **录屏**：录制所选窗口、整个屏幕或框选的屏幕区域，支持 30/60 fps、系统声音、麦克风、实时计时与停止；保存为 MP4 到 `影片/长截屏`。
- **麦克风录制**：在录屏选项里与系统声音并排的“录制麦克风”开关；默认关闭，开启后会请求麦克风权限。系统声音和麦克风会作为两条 AAC 音轨写入 MP4，应用内播放器自动混音。
- **内置视频播放**：录屏结果页和外部视频都可在应用内播放、暂停、拖动进度；也可以交给系统默认播放器。
- **图片查看器**：截图结果和外部图片都可全屏查看，切换适合宽度 / 100% / 200%，滚动检查长图细节。
- **快速保存**：截图和录屏结果页都有“快速保存到下载”，快捷键 ⌘S；需要选择位置时使用“另存为…”（⇧⌘S）。
- **统一的保存结果页**：录屏结束后会像截图一样进入完整结果页，显示播放器、视频信息、保存和 Finder 操作。
- **打开外部媒体**：支持文件菜单（⌘O）、“打开媒体”按钮、拖拽文件，以及 Finder 的“打开方式 → 截录”；可打开 PNG/JPEG/HEIC/TIFF 等图片和 MP4/MOV 等视频。
- **独立录制窗口**：录屏页的窗口选择使用独立状态和独立选择面板，不会读取或改变截屏页选中的窗口。
- **结果处理**：自动保存 PNG 到 `图片/长截屏`，支持预览、另存为、复制到剪贴板和在 Finder 中显示。
- **记忆设置**：重叠区域、滚动等待时间会保存在本机。

## 使用

1. 打开“截录”。
2. 首次使用按提示授予：
   - **屏幕录制**：读取窗口画面。
   - **辅助功能**：向所选窗口发送滚动事件。
   - **麦克风**：仅在打开“录制麦克风”并开始录屏时请求。
3. 在首页选择 **截屏** 或 **录屏**。
4. 截屏页：
   - **截取范围**选择“窗口”或“框选区域”。
   - **截取方式**选择“普通截屏”或“长截屏”。
   - 窗口模式：点“选择窗口”打开窗口面板，选好后点右下角开始。
   - 框选模式：点“框选区域”拖出范围，确认后回到页面，再点右下角开始。
5. 长截屏模式可在“设置选项”中点“调整…”修改重叠区域（默认 55%）和滚动等待；普通截屏不需要辅助功能权限。
6. 录屏页：独立选择“窗口 / 整个屏幕 / 框选区域”。窗口选择会打开一个独立的窗口选择面板，不会跳到截屏页；选择框选区域时，拖动框选并确认，再点“开始录制”。可调整 30/60 fps、系统声音和麦克风；麦克风首次使用会弹出系统授权提示。
7. 完成后主窗口会重新出现，截图或长图已自动保存。结果页可点“快速保存”立即复制到“下载”，或用“另存为…”选择位置；截图还能用适合宽度 / 100% / 200% 查看。
8. 录屏结束后会进入与截图一致的完整结果页：可直接播放、暂停、拖动进度，也可快速保存到下载、另存为、定位到 Finder 或用默认播放器打开。
9. 查看已有文件：按 ⌘O 或点首页“打开媒体”，也可以把图片/视频拖到窗口里，或在 Finder 中右键选择“打开方式 → 截录”。外部图片同样支持 100%/200% 查看。

快捷键：

| 操作 | 快捷键 |
| --- | --- |
| 执行截屏 | ⌘ ↩ |
| 停止截屏 | ⌘ . |
| 选择框选区域 | ⌘ ⇧ 2 |
| 录制所选窗口 | ⌘ ⇧ 3 |
| 录制整个屏幕 | ⌘ ⇧ 4 |
| 框选录制区域 | ⌘ ⇧ 5 |
| 停止录屏 | ⌘ ⇧ . |
| 刷新窗口列表 | ⌘ R |
| 保存副本 | ⌘ S |

> 普通截屏只需要“屏幕录制”；长截屏模式还需要“辅助功能”来发送滚动事件。首次授权后 macOS 可能要求重新打开应用。屏幕录制和辅助功能权限与代码签名绑定。打包脚本会优先使用本机 Apple Development 证书签名，保证后续重新构建时权限记录仍然匹配。
>
> 如果更新后系统设置里的开关是打开的、应用却仍提示无权限，说明旧签名记录已失效，执行：
>
> ```bash
> tccutil reset ScreenCapture com.seven.longshot
> tccutil reset Accessibility com.seven.longshot
> ```
>
> 然后重新打开应用并再授权一次。

## 实现说明

- `LongShotCore`：独立的图像核心。
  - `BGRAImage`：统一 BGRA 位图，保留全高度灰度采样，避免缩放导致半像素错位。
  - `FrameAligner`：固定页头下方多探针粗匹配 + 全分辨率精修 + 重叠区验证。
  - `StitchCanvas`：磁盘后备画布，每次只把新出现的行追加到临时 BGRA 文件；内存占用与图片长度无关。
- `PNGEncoder`：流式 zlib/PNG 编码器，逐块读取原始行并写出 IDAT，避免一次性把整张长图载入内存。
- `TiledImagePreview`：AppKit 分块预览，只绘制视口内像素，支持 100% 像素级查看。
- `RegionSelectionController`：全屏框选浮层，支持拖动、回车确认、Esc 取消。
- `RegionResolver`：找到框选区域下方最前面的窗口，用于激活和滚动。
- `CaptureEngine`：支持窗口/区域裁剪，以及普通单帧截屏和长截图；普通模式截取第一帧后直接保存，长截图模式进入滚动拼接管线。
- `ScreenRecorder`：ScreenCaptureKit + AVAssetWriter，将窗口或显示器画面编码为 H.264 MP4；系统声音和麦克风分别写入两条 AAC 音轨，实时混音由播放器完成。录制悬浮条通过排除本应用窗口避免进入画面。
- `Sources/LongShot`：采集、滚屏、权限、HUD 和 SwiftUI 界面。
- 长图仅受磁盘空间限制；应用会预留 1 GB 安全空间，低于该值时停止并保存已截取的无缝内容。

## 已知限制

- 普通截屏不滚动；长截图滚动完全依赖系统合成事件。个别禁用滚轮滚动、使用自定义滚动容器或需要特殊手势的应用可能无法自动滚动。
- 固定底部工具条会在长图中重复出现；当前版本未做固定底栏识别。
- 框选区域截取的是屏幕上实际可见的内容；如果有其他窗口遮挡，遮挡内容也会进入截图/长图。长截屏会激活区域下方最前面的窗口并自动滚动。
- 框选区域只在发起框选的当前显示器上生效；多显示器时可先把应用窗口移到目标屏幕。
- 录屏为 H.264 MP4（有损视频编码，文件更小、兼容性更好），与长截图的 PNG 无损画质是两套独立流程。
- 全屏录制会包含菜单栏和 Dock；区域录制只包含屏幕上该区域实际可见的内容，其他窗口遮挡也会被录进去。系统声音开关默认开启，麦克风默认关闭；麦克风录制需要 macOS 15 或更高版本和系统授权。
- 部分应用常驻显示的滚动条会出现在图片最右侧。
- 页面包含持续动画、视频或大面积完全重复内容时，重叠识别可能提前停止并保留已截取部分。
- 极长图片会占用大量磁盘（原始 BGRA 缓冲 + 最终 PNG），这是“无长度限制”的物理边界；可在结果页查看 PNG 体积。
- 临时原始像素文件位于 `~/Library/Application Support/com.seven.longshot/Captures`，结果关闭、应用退出或下次启动时自动清理。
- 超过约 600 MB 的 PNG 不会复制到剪贴板，请使用“保存副本”或直接分享文件。
- ChatGPT 等平台会把图片的最长边限制在约 2047 px。2816 × 62108 px 的长图整张上传会变成约 93 × 2047 px，因此必须使用“导出上传分段”。
- 应用使用本机 Apple Development 证书签名，未做 Apple 公证；仅在本机使用。
